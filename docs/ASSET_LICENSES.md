Original assets created for this project (procedural Blender models, synthesized audio, procedural textures) are owned by the project and generated by scripts in `tools/`.

**PBR textures (ambientCG / Poly Haven):** licence pages checked on 2026-10-08 (https://docs.ambientcg.com/license/ and https://polyhaven.com/license — all assets CC0 1.0). Paths above are relative to `game/assets/`. All scanned maps were downscaled to 1K (2K for floor and wall), colour-graded to the palette in `docs/ART_DIRECTION.md` and repacked (albedo / OpenGL normal / ORM) by `tools/textures/fetch_textures.py`, which re-downloads and rebuilds them. `textures/chalkboard` is procedural (original). **Fonts:** licence verified from each family's `METADATA.pb` (`license: "OFL"`) and `OFL.txt` in google/fonts; none declares a Reserved Font Name, so the static Cormorant instances (made with fontTools by `tools/fonts/fetch_fonts.py`) stay under OFL 1.1.

**Audio:** every file in `game/assets/audio/` is synthesised by `tools/audio/synth_all.py` (original), except that `page_turn` mixes in the one Kenney CC0 recording listed above. CC0 was verified on 2026-10-08 in two places: the asset page (https://kenney.nl/assets/rpg-audio, "Creative Commons CC0") and the `License.txt` inside the downloaded pack ("License (Creative Commons Zero, CC0)"). The Kenney "Impact Sounds" and "Interface Sounds" packs (also CC0) were evaluated but not used.

**3D dressing props (Poly Haven models):** licence page https://polyhaven.com/license re-checked on 2026-10-08 (all Poly Haven assets CC0 1.0), and each asset page `https://polyhaven.com/a/<id>` was confirmed to state CC0; authors are taken from the `authors` field of `https://api.polyhaven.com/info/<id>`. The 1k glTF downloads were md5-verified, then decimated, re-pivoted and repacked into single `.glb` files with the original 1K JPG textures embedded by `tools/models_cc0/fetch_cc0_models.py` (details and per-prop data in `docs/CC0_PROPS.md`). Kenney CC0 kits were evaluated and not used (style mismatch, see `docs/CC0_PROPS.md`).

**Chapter 2 decals: original procedural.** Everything in `textures/decals/ch2/` (glyphs, vault engraving, film frames, secret and vault reels, routing chart, destination ring, badge with its portrait, index/request cards, file cover, tape labels, film strips, reel-can lid, lantern slide, rules notice, box-label atlas) and the `textures/linoleum/` set are original artwork generated by `tools/textures/make_decals_ch2.py` (PIL + numpy, no third-party images; fonts: the OFL families above, URW base35 and DejaVu from the system). The Chapter 2 material slots in `tools/materials/make_extra_materials.py` reuse only the CC0 texture sets listed above.

**Logo and app icon: supplied by the project owner.** The owner chose this artwork on 2026-10-09; the source file is `docs/brand/logo_source.png`, kept outside the Godot project so it is not exported. Two derived sets are made by `tools/ui/make_logo_variants.py`:
- the localized logos `ui/logo/logo_{en,ru,uz}.png`, where the RU/UZ subtitle is re-engraved with Cormorant Garamond (OFL);
- the app icons `ui/icon*.png` and `docs/store/graphics/icon_512.png`, cut from the emblem. The monochrome icon is drawn procedurally.

**Open item before store release:** the owner must confirm where the artwork came from and that it may be used commercially. If an AI image tool made it, check that tool's terms.
