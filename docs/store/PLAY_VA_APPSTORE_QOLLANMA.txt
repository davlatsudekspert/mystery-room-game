2.3 API kaliti: rol ADMIN boʻlishi shart
-------------------------------------------------------------------------------
Siz ASC_KEY_ID / ASC_ISSUER_ID / ASC_KEY_P8_BASE64 secretlarini qoʻshgansiz.
Faqat kalit rolini tekshiring:
App Store Connect → Users and Access → Integrations → App Store Connect API →
Team Keys → kalitingiz qatoridagi «Access» ustuni.
   - «Admin» boʻlsa → hech narsa qilmang.
   - Boshqa rol boʻlsa (App Manager, Developer...) → «+» bilan yangi kalit
     yarating: Name: MysteryRoom CI, Access: Admin → Generate → .p8 faylni
     yuklab oling (faqat 1 marta beriladi) → GitHub secretlarini yangilang:
       ASC_KEY_ID        = yangi Key ID
       ASC_ISSUER_ID     = sahifa tepasidagi Issuer ID (oʻzgarmaydi)
       ASC_KEY_P8_BASE64 = .p8 faylning base64 matni
     Windows PowerShell'da base64 olish:
       [Convert]::ToBase64String([IO.File]::ReadAllBytes("C:\yol\AuthKey_XXXX.p8"))
     Mac'da: base64 -i AuthKey_XXXX.p8
