# Narration script with timings

English voice-over (spoken). The Russian and Uzbek lines are subtitles only. Times are seconds from the start of each video; the
line is meant to start at the given time and the voice track is mixed under the music, which ducks while the voice speaks.
The shipped videos use the offline neural voice piper `en_GB-cori-high` (see README.md). If the owner prefers to record the lines with another
voice tool, record each line as a separate file, name it by its id (T1.wav ...), put it in `$PROMO_WORK/voice/` and run `python3 promo/build_videos.py`.
Style: calm, low, slow, a little breathy, nothing dramatic; leave the pause marked by `...`.
